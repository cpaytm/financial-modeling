# 겟차 FY26 — 적용 사례

본 프레임워크의 첫 적용 사례. Case A 경로(기존 엑셀 → 인터랙티브 트리 변환).

`index.html`을 브라우저에서 열면 바로 실행된다.

---

## 개요

| 항목 | 값 |
|------|-----|
| 대상 | 겟차(Getcha) FY26 사업계획 |
| 입력 | 엑셀 20개 시트, 2025년 실적 + 2026~2031년 추정 |
| 산출물 | 단일 HTML (~92KB, 1,500줄) |
| 매출 BM | 차량대여 / 거래중개 / 플랫폼 / 중고차 / 기타 (5개) |
| 비용 체계 | 변동원가(BM별) / 고정비(7계정) / 이자비용(2계정) |
| 가정변수 | 매출 30개 + 비용 25개 = 총 55개 |
| 소요시간 | 약 1시간 (분석 + 트리 생성 + 정합성 레퍼) |

---

## 방법론이 드러낸 인사이트

- **매출 Mix 전환**: 25년 거래중개 59% → 31년 차량대여 63%. 플랫폼 사업에서 Fleet 운용 사업으로 밸류 드라이버가 완전 전환.
- **Fleet = 매출과 비용의 공유 드라이버**: 31년 Fleet 8,940대 가정 하에 렌트수익 1,589억, 감가상각 858억, 이자 93억. 매출-비용 교차 참조의 전형 사례. 시뮬레이터에서 Fleet를 한 번 조정하면 매출·비용·B/S가 동시에 움직임.
- **영업레버리지**: 고정비 59억→161억(2.7배) 증가하는 동안 매출 257억→3,075억(12배) 증가. 영업이익률 -3.6% → 19.8%로 급개선.

엑셀만 봐서는 보이지 않던 구조가 트리 분해와 교차 참조로 가시화됨.

## 인터랙션

| 입력 | 동작 |
|------|------|
| 노드 클릭 | 펼침/접힘 토글 |
| 우측 차트 아이콘 클릭 | 연도별 바 차트 팝업 |
| 매출합계 차트의 연도 막대 클릭 | BM별 증감 워터폴 (1~2년 선택 가능) |
| 노드 드래그 | 위치 자유 조정 (부모 이동 시 자식 동반) |
| 빈 영역 드래그 | 캔버스 pan |
| 휠 | 마우스 기준 zoom |
| 상단 "시뮬레이터" 버튼 | 사이드 패널 토글 |
| 시뮬레이터 슬라이더 | 가정변수 조정 → 실시간 재계산 |
| 시뮬레이터 "케이스" 버튼 | Case A/B/C... 저장·전환 |
| 상단 "테이블 보기" | P&L 표 |
| 상단 "가정변수" | 55개 변수 일람 |
| ESC | 모든 팝업 닫기 |

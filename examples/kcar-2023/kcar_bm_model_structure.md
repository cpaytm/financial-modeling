# 케이카 2023 재무모델 BM / 모델 구조

## 1. 회사 / 사업 개요

- 회사
  - 케이카

- 업종
  - 중고차 매입 / 판매 플랫폼
  - 오프라인 지점 기반 중고차 판매
  - 온라인 이커머스 기반 중고차 판매
  - 경매, 렌터카, 용역, 기타 부가 매출 보유

- 핵심 고객
  - 중고차를 구매하는 개인 고객
  - 중고차를 처분하거나 경매 채널을 이용하는 고객
  - 렌터카 또는 장기렌트 관련 고객

- 한 문장 BM
  - 케이카는 중고차를 확보해 상품화한 뒤, 이커머스와 지점내방 채널을 통해 차량을 판매하고, 경매 / 렌터카 / 용역 매출을 더해 수익을 창출하는 중고차 유통 사업자임

## 5. 매출 모델 구조

- 중고차 매출
  - 핵심 매출원
  - 채널별로 이커머스와 지점내방을 분리함
  - 각 채널 안에서 차급별 Q x P 모델을 구성함

- 이커머스 중고차 판매
  - 온라인 채널 매출
  - 차급별 판매대수와 가격으로 계산함
  - 주요 드라이버
    - 차급별 시장판매대수 성장률
    - 차급별 케이카 점유율
    - 차급별 평균판매가격 성장률

- 지점내방 중고차 판매
  - 오프라인 지점 방문 기반 매출
  - 이커머스와 같은 차급 구조를 사용함
  - 주요 드라이버
    - 차급별 시장판매대수 성장률
    - 차급별 케이카 점유율
    - 차급별 평균판매가격 성장률

- 경매 매출
  - 상품 매출과 용역 매출로 구분함
  - 실습 모델에서는 성장률 기반 매출로 단순화 가능함

- 렌터카 매출
  - 렌터카 매각 매출
  - 장기렌트 매출
  - 실습 모델에서는 별도 세부 Q x P 없이 성장률 기반 매출로 단순화 가능함

- 용역 / 기타 매출
  - 이커머스 용역 매출은 이커머스 중고차 매출 대비 비율로 계산 가능함
  - 지점내방 용역 매출은 지점내방 중고차 매출 대비 비율로 계산 가능함
  - 기타 매출은 주요 매출 합계 대비 비율 또는 성장률로 계산 가능함

## 6. 비용 모델 구조

- 재고자산원가
  - 중고차 판매의 핵심 원가
  - 계산 방식
    - 중고차 판매대수 x 중고차 1대당 원가
  - 실습상 가장 중요한 매출총이익률 드라이버임

- 판매보증비
  - 판매 차량에 붙는 보증 관련 비용
  - 계산 방식
    - 중고차 판매대수 x 중고차 1대당 보증비

- 차량매각원가
  - 렌터카 매각 매출에 대응되는 원가
  - 계산 방식
    - 렌터카 매각 매출 x 차량매각원가율

- 변동비
  - 지급수수료
  - 부품비
  - 세금과공과
  - 위탁차량비
  - 소모품비
  - 보험료
  - 기타비용

- 변동비 계산 방식
  - 대부분 Total Sales 또는 특정 매출 대비 비율로 계산함
  - 실습 모델에서는 주요 변동비율 몇 개만 선택해 단순화 가능함

- 고정비
  - 여비교통비
  - 대손상각비
  - 접대비
  - 지급임차료
  - 차량유지비
  - 운반비

- 고정비 계산 방식
  - 과거 실적을 기준으로 성장률을 적용함
  - 매출과 직접 연결하기보다 비용 항목별 증가율로 관리함

## 7. 인건비 모델 구조

- 인건비 구분
  - 중고차 판매 인력
  - 경매 인력
  - 렌탈 인력
  - 마케팅 / IT / 사무 인력

- 중고차 판매 인력
  - 판매대수와 1인당 판매대수를 바탕으로 필요 인원을 추정함
  - 평균급여를 곱해 급여를 계산함

- 경매 인력
  - 경매 매출과 1인당 경매매출을 바탕으로 필요 인원을 추정함
  - 평균급여를 곱해 급여를 계산함

- 렌탈 인력
  - 렌탈 매출과 1인당 렌탈매출을 바탕으로 필요 인원을 추정함
  - 평균급여를 곱해 급여를 계산함

- 마케팅 / IT / 사무 인력
  - 인원 수를 직접 가정함
  - 평균급여를 곱해 급여를 계산함

- 기타 인건비
  - 퇴직급여
  - 복리후생비
  - 주식보상비용

- 실습 단순화 방향
  - 인력 모델을 전부 구현하지 않아도 됨
  - 중고차 판매 인력과 공통 인력만 남기고, 나머지는 매출 대비 비율 또는 성장률로 처리 가능함

## 9. 운전자본 모델 구조

- 운전자본 항목
  - 매출채권
  - 재고자산
  - 기타유동자산
  - 매입채무및기타채무
  - 기타유동부채

- 계산 기준
  - 매출채권 = Sales x 매출채권 비율
  - 재고자산 = 재고자산원가 x 재고자산 비율
  - 기타유동자산 = Sales x 기타유동자산 비율
  - 매입채무및기타채무 = 변동비 x 매입채무 비율
  - 기타유동부채 = 변동비 x 기타유동부채 비율

- 현금흐름 반영
  - NWC 증가 = FCFF 차감
  - NWC 감소 = FCFF 가산

- 실습 단순화 방향
  - DSO / DIO / DPO를 직접 쓰기보다 매출 / 원가 대비 비율로 먼저 구현함
  - 이후 고급 실습에서 회전일수 방식으로 확장 가능함

- 밸류에이션
  - 영업모델의 변화가 Equity Value와 주당가치까지 연결되는가?
  - WACC와 Terminal Growth가 별도의 민감도 변수로 표현되는가?

## 13. 실습용 단순화 제안

- 매출 단순화
  - 원본: 이커머스 / 지점내방 x 7개 차급
  - 실습: 이커머스 / 지점내방 x 3개 차급으로 축소 가능
  - 추천 차급
    - SUV
    - 일반 승용
    - 기타

- 비용 단순화
  - 원본: 상세 변동비 / 고정비 / 인건비 모델
  - 실습: 핵심 원가, 보증비, 주요 변동비, 인건비, 기타 고정비로 축소 가능

- 인건비 단순화
  - 원본: 기능별 / 성별 / 생산성별 세부 구조
  - 실습: 판매 인력과 지원 인력으로 축소 가능

- 운전자본 단순화
  - 원본: 항목별 비율과 회전일수 지표 병행
  - 실습: 매출 / 원가 대비 비율로 먼저 구현 가능

- 밸류에이션 단순화
  - 원본: DCF 기반 Equity Value와 주당가치
  - 실습: FCFF, Terminal Value, Enterprise Value, Equity Value, 주당가치까지만 구현 가능

- 사람이 판단해야 하는 작업
  - 어떤 차급과 비용 항목을 실습에 남길지 결정
  - 원본 모델의 가정이 합리적인지 판단
  - valuation에서 핵심 민감도 변수를 선택
  - 수강생에게 보여줄 난이도 조절

- Deterministic하게 고정해야 하는 작업
  - Excel 수식 구조
  - 기간별 링크
  - 합계 / 소계 검산
  - FCFF 계산
  - DCF 할인 계산
  - 주당가치 계산

- 핵심 원칙
  - LLM은 구조화와 초안 생성에 사용함
  - Excel은 계산과 검산의 최종 시스템으로 사용함
  - HTML은 LLM의 구조화 결과를 사람이 검토하는 중간 작업대로 사용함
